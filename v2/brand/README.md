# Calm API logo

The lotus: calm, open, growing. Drawn in fine lines for headers and banners, solid for icons.

## Files

| File | Use |
|---|---|
| `calmapi-logo.svg`, `calmapi-logo.png` | Lotus and wordmark, on light backgrounds |
| `calmapi-logo-light.svg` | The same, for dark backgrounds |
| `calmapi-logo-tagline.svg`, `calmapi-logo-tagline.png` | With "Keep Calm & REST" (`-light` for dark backgrounds) |
| `calmapi-mark.svg`, `calmapi-mark-512.png` | The line lotus alone (`-light` for dark backgrounds). 32 px and up |
| `calmapi-mark-solid.svg`, `calmapi-mark-solid-512.png` | The solid lotus, for small sizes and one-color use |
| `calmapi-icon.svg`, `calmapi-icon-512.png`, `calmapi-icon-192.png` | App icon: navy rounded tile (web app manifest) |
| `favicon.svg`, `favicon.ico`, `favicon-16/32/48.png` | Browser tabs |
| `apple-touch-icon.png` | iOS home screen (180 px, full bleed: iOS rounds the corners) |
| `calmapi-icon-square.svg`, `calmapi-avatar-512.png` | GitHub, npm and social avatars (full bleed, safe for a circle crop) |
| `calmapi-banner.svg`, `calmapi-banner.png` | README banner, 1920 x 1080 (`-dark` for dark pages) |
| `calmapi-social.svg`, `calmapi-social.png` | Social preview, 1280 x 640 (GitHub Settings > Social preview) |
| `calmapi-mandala.svg` | The banner's mandala on its own |

Text in the SVG files is converted to outlines, so they look the same without the fonts installed.

## Color

| Name | Hex | Use |
|---|---|---|
| Navy | `#002F80` | The logo, headings, the icon tile |
| Soft blue | `#496AA3` | Secondary text, links |
| Mist | `#93A5C6` | Rules and dividers |
| Paper | `#F6F6F6` | Light background, the lotus on the icon |
| Night | `#0B1730` | Dark background |
| Moon | `#DCE5F5` | The logo on dark backgrounds |

## Type

- Wordmark: Spectral Regular, tracking +1%.
- Tagline and supporting text: IBM Plex Sans Italic.

Both are open source (SIL Open Font License).

## Using it

- Keep the height of the center petal free around the logo.
- Line lotus at 32 px and larger; below that, the solid lotus or the app icon.
- One color only: navy on light backgrounds, moon on dark ones. Do not recolor the petals separately, add effects or stretch it.
- The wordmark is "Calm API" with a space; in code and commands the name stays `calmapi`.
